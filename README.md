# Construction BOQ Calculator

A lightweight, browser-based Bill of Quantities (BOQ) calculator for construction estimating.

## Features

- Add and remove BOQ items
- Enter descriptions, units, quantities, and unit rates
- Calculate line totals and the grand total automatically
- Choose from common currencies (including EGP, USD, EUR, GBP, SAR, and AED)
- Export the estimate as a CSV file that can be opened in spreadsheet software
- Runs locally in your browser; no account, server, or external dependency required

## Professional V1 candidate

The in-progress Professional BOQ V1 candidate and its release gates are documented in [V1 Release Readiness](V1-RELEASE-READINESS.md). This candidate is under review and is not yet approved for production.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add your BOQ items and select the currency.
4. Select **Export CSV** to download your estimate.

## Scope and limitations

This is an initial estimating aid. It does not calculate quantities from drawings, validate market rates, apply taxes or overhead automatically, or replace professional review. Users are responsible for checking quantities, rates, units, and contract requirements.
